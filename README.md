# Imposter Game

A small browser-based social deduction game built with plain HTML, CSS, and JavaScript.

## What it does

- Randomly assigns one of four crew members as the imposter.
- Gives the player up to three observation rounds.
- Generates imperfect evidence for each crew member.
- Tracks suspicion levels, score, and win streak.
- Rewards earlier correct accusations with more points.
- Works on desktop and mobile without any external libraries.

## Run locally

No build step is required. Download the repository and open `index.html` in a browser.
