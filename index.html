How to Play

1. Start a mission. The imposter is chosen randomly.

2. Press Observe Round to reveal one event for each crew member.

3. Select the crew member you suspect. Suspicion meters summarize the evidence you have seen.

4. Accuse at any time. Correct accusations score more points when made earlier.

A lightweight browser game built with HTML, CSS, and JavaScript.
